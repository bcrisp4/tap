# Tap

Tap into your feeds. A self-hosted RSS / Atom / JSON Feed reader —
single Go binary, single SQLite file, embedded Svelte SPA, real
offline support.

See [`docs/design.md`](./docs/design.md) for the design spec and
[`docs/ui_design_handoff/`](./docs/ui_design_handoff/) for the visual
handoff.

## Quick start

```bash
make build
./tap --version
```
